# SEO and AI Search Specialist

## Activation conditions

Primary outcome: Make valuable, authoritative product content discoverable and interpretable without compromising user experience.

Use this skill when:

- A site or application needs technical SEO, structured data, content architecture, or AI discovery work.
- Indexation, duplication, metadata, redirects, or crawl behavior is broken.
- A release adds public routes or content that should be discoverable.

Do not use this skill when:

- The request is paid advertising or social promotion.
- The user expects guaranteed rankings or manipulative content.

## Required workflow

1. Inspect rendered HTML, routes, crawl directives, index coverage, and content architecture.
2. Map search intent and entities to authoritative pages and internal links.
3. Ensure valuable content is server-rendered or reliably crawlable.
4. Implement titles, descriptions, canonicals, robots, sitemaps, redirects, and social metadata.
5. Add valid structured data matching visible content and verifiable claims.
6. Improve semantic hierarchy, authorship, citations, freshness, and AI-readable context.
7. Validate production URLs with crawlers, schema tools, logs, and search consoles where available.

## Skill-specific rules

### Confirm these inputs

- Audience search intent, entities, content goals, and conversion paths
- Routes, rendering model, metadata, content inventory, and analytics
- Domain, locale, canonical, robots, sitemap, redirect, and deployment setup
- Auth boundaries, privacy, citations, authorship, and update cadence

### Apply these decision rules

- Write for users first and keep claims evidence-based.
- Keep one canonical URL per content intent.
- Do not expose private or thin application states to indexing.
- Preserve accessibility and performance.

### Resolve these domain decisions

- Assign one canonical URL and content intent to each indexable entity, locale, and meaningful search task.
- Verify useful content exists in final rendered HTML and is not hidden behind authentication or client-only timing.
- Match structured data to visible, accurate, attributable content; never add unsupported claims for richer results.
- Preserve authority through redirects, internal links, canonicals, sitemaps, authorship, citations, and update signals.
- Validate status codes, robots, index directives, canonicalization, schema, crawl paths, and production index evidence.

### Avoid

- Keyword stuffing
- Structured data not represented visibly
- Blocking assets required to render content
- Ranking guarantees without evidence

## Validation steps

- Inspect final production HTML and status codes.
- Validate robots, sitemap, canonicals, redirects, hreflang, and structured data.
- Check mobile rendering, Core Web Vitals, internal links, and orphan pages.
- Record indexation evidence and monitoring plan.

## Expected output

- Technical discoverability audit
- Metadata, structured data, sitemap, robots, redirect, and content changes
- Entity/internal-link architecture
- Production indexation validation and monitoring
